# dsh-nav-fold · v0.4.11

> 一个插件整理 DSH 左侧栏：收起全局导航、按需开启工作区三栏，并用自定义入口快捷键进入文件夹／会话焦点导航。也可通过「无线麦」映射小米蓝牙遥控器按键；Fold 不直接连接蓝牙设备。macOS 顶部 Logo 隐藏功能收录并适配 [stoner-byte 的 dsh-hide-brand](https://github.com/stoner-byte/dsh-hide-brand)（MIT）。

**一条细线，收起全局导航。工作区视图，按需开启。**

点击侧栏导航底部，面板列表收成一排图标；再点一下，回到熟悉的列表。工作区与会话留在原位。

## 安装与升级

**v0.4.11 安装：**从 [GitHub Release](https://github.com/nico-zhuang/dsh-nav-fold/releases/tag/v0.4.11) 下载 `dsh-nav-fold-0.4.11.tgz`，或用 DSH CLI 安装：

```sh
dsh plugin add https://github.com/nico-zhuang/dsh-nav-fold/releases/download/v0.4.11/dsh-nav-fold-0.4.11.tgz
```

已针对 **DSH 0.2.1-rc.5 与 0.2.2-rc.1** 两个已发布构建分别核对原生侧栏结构并做自动化回归；不代表 0.2.1 的所有子版本均已验证。升级后正常重启 DSH；三栏依旧**默认关闭**，若旧版安全隔离曾将其保存为关闭，需在插件配置中重新保存开启。上一公开版 [v0.4.10](https://github.com/nico-zhuang/dsh-nav-fold/releases/tag/v0.4.10) 保留下载与重装回退入口；这仍是 GitHub Release `.tgz` 发布，不是 npm 包发布。

## 左侧栏优化，按需开启

设置在 **插件 → 已安装 → dsh-nav-fold → 配置**，按用途分为两组；三个开关各自保存，不相互替代：

- **浏览与导航**：开启并保存「工作区／活动／收藏三栏」，再确认「会话焦点导航」已开启。到 **DSH 设置 → 快捷键**，给「会话导航 / Navigate sessions」绑定入口组合键（无预设）。进入后 ↑↓移动焦点，←→切换三栏；Enter 展开文件夹或打开会话，Esc 退出。需要遥控器时，可在「无线麦」中把小米蓝牙遥控器的“进入列表”按键映射到同一组合键；Fold 不负责设备配对。
- **空间整理**：可独立开启「隐藏顶部 Logo」（仅 macOS），不要求打开三栏。这项功能收录并适配 [stoner-byte 的 dsh-hide-brand](https://github.com/stoner-byte/dsh-hide-brand)，许可与来源见 [第三方声明](THIRD_PARTY_NOTICES.md)。

v0.4.11 让选中状态的 Tab 使用随深浅主题调整的更柔和填色，并去掉折叠导航中宿主 8px 与 Fold 自身 6px 的重复上下间距；不调整宿主「新会话」或底部操作入口。v0.4.10 在 rc.1 上把会话行三点操作交回 DSH 原生菜单，rc.5 保留旧版回退，不修改已保存偏好。已验证自动化行为测试；**新版菜单尚无已认证的真实 DSH GUI 点击验收，实体遥控器组合操作也未亲测**，不将源码或模拟测试称为现场验收。

## 交互，刚好够用

- **点一下**：展开或收起。图标与细线从当前位置平滑移动，连续点击也能立即反向。
- **停一下**：面板名称直接替换细线中央的箭头；移开后箭头回来。键盘聚焦图标时同样能看到名称，不必等待原生提示。
- **拖一下**：把常用图标移到顺手的位置，顺序保存在本机。也可以聚焦图标后按 `Alt + 方向键` 排序。

侧栏变宽或变窄时，图标由原生布局即时等距重排、自动换行；末行沿左侧列位对齐。点击展开或收起时仍有可中断的平滑动画，箭头低调呼吸，细线纤细淡出；系统选择「减少动态效果」时，移动与呼吸动画自动停止。新增的面板也会加入，不影响工作区和会话。

## v0.4.3 新增：工作区／活动／收藏（默认关闭）

启用路径：**插件 → 已安装 → dsh-nav-fold → 配置 → 勾选「工作区／活动／收藏三栏」→ 保存三栏设置**。仅安装插件、点侧栏按钮或旧版浏览器偏好都不会替你打开三栏；配置尚未保存时仍显示 DSH 原生工作区。开启后，工作区沿用原生树，活动展示待处理／运行／近期会话，收藏读取 DSH 自身的置顶会话，不另建收藏数据。点击栏目不会切换当前打开的会话。重新关闭并保存后，插件的三栏和替代视图一起撤出，原生工作区立即回来。

**以下是 v0.4.3 历史设计，非当前 v0.4.10 布局**：三个 15px 线性图标居中，收藏为轻微斜置的 Pin；横框右侧曾有独立的 Tab 隐藏按钮，并以左侧留白平衡。该版本的折叠仅是浏览器显示偏好，不关闭活动／收藏视图。v0.4.7 已移除这个控件与旧本地偏好读取，改为下文的通栏布局。

### 会话悬停操作（DSH rc.1 原生菜单；rc.5 兼容回退）

活动和收藏会话行在鼠标悬停或键盘聚焦时显示操作按钮；触屏不依赖悬停。在支持公开会话上下文菜单的 DSH 0.2.2-rc.1 中，每行只有一个三点按钮，标题只为该按钮留位；点击三点、右键或 Shift+F10 均打开 DSH 共享的原生会话菜单，不会切换当前会话。置顶／取消置顶、重命名、分叉、复制 ID、归档及运行中归档的权限与确认流程均由宿主处理，Fold 不再绘制独立 Pin／归档按钮或自己的菜单。

在尚无完整公开菜单入口的 DSH 0.2.1-rc.5 中，仍保留原有三点、Pin、归档三个按钮及 82px 标题留位；Pin／归档调用 DSH `uiWorkspace` 接口，失败提示重试，不另存收藏数据。此兼容菜单并非宿主完整右键菜单，不提供原生重命名／分叉。下方 v0.4.4 截图仅展示 rc.5 的历史布局，不代表 rc.1 的单按钮布局。

### v0.4.5 历史兼容路径：DSH 0.2.1-rc.5 的活动与收藏会话归档

以下仅描述 DSH 0.2.1-rc.5 的旧版回退行为：活动和收藏行有独立归档按钮，三点菜单也提供归档；两者均调用 DSH 原生 `uiWorkspace.archiveSession`，不跳转、不直接改写会话文件或自建归档状态。请求成功后仍等待宿主更新 `archivedSessionIds` 才移除行，不提前假装归档成功。请求中阻止重复提交及并发 Pin；普通失败保留会话并提示重试。

在此 rc.5 回退路径中，如果宿主明确拒绝归档运行中的会话，Fold 才显示「归档并停止」确认；取消不停止任务，确认后才调用 `archiveSession(id, { stopActivity: true })`。确认失败时保留弹窗及错误提示供重试；缺失归档 API 时按钮不可用，不猜测其他停止或删除路径。**此运行中路径仅经过模拟测试，未用真实模型密钥或真实运行任务验收。**

### v0.4.7：快捷键驱动的会话焦点导航

Fold 不直接连接蓝牙设备，而是使用 DSH 已有快捷键：在 **插件 → 已安装 → dsh-nav-fold → 配置** 保存启用「工作区／活动／收藏三栏」并确认「会话焦点导航」开关已启用，再到 **DSH 设置 → 快捷键 → 会话导航 / Navigate sessions** 自行分配入口组合键；将小米蓝牙遥控器通过「无线麦」的“进入列表”按键映射到该组合键。Fold 没有预设快捷键，不修改「无线麦」或遥控器配置；绑定前检查 DSH 已注册命令冲突，并留意其他插件自行监听的全局按键。

进入导航后，↑↓移动当前栏中可见文件夹或会话的真实键盘焦点，**不会自动打开会话**；←→切换「工作区／活动／收藏」；Enter 在会话上才打开它，在工作区原生文件夹上则调用宿主原有点击来展开／收起并保留导航焦点；Esc 退出并尽可能回到进入前的焦点。折叠文件夹的隐藏子项不会进入遍历。编辑框、弹窗以及 DS-Bot 占用侧栏时不抢走方向键；原有 `Alt + 方向键` 面板排序不受影响。关闭会话导航开关会退出焦点模式并释放 Fold 的命令注册，保留三栏和用户在 DSH 中的快捷键绑定。实体小米遥控器与当前 DSH GUI 的整套组合操作仍需维护者亲测。

### v0.4.7：通栏三栏与节省空间的去 Logo 开关

三个 Tab 不再有右侧隐藏按钮，也不读取旧版的“折叠 Tab”本地偏好；启用三栏后保持可见，沿用原生侧栏内容宽度，与「新会话」约等宽。侧栏自身折叠成 rail 时仍由 DSH 原生布局隐藏三栏。上面的 v0.4.3 截图是历史示例，**不代表当前通栏样式**。

「隐藏顶部 Logo」是 Fold 中独立保存的开关，默认关闭，**无需开启三栏也能使用**。Fold 在 macOS 仅隐藏顶部纯展示的鲸鱼／字标行，让「新会话」上移，为会话列表留出空间；关闭开关或停用 Fold 后移除自身样式。该功能**收录并适配 [stoner-byte 的 dsh-hide-brand](https://github.com/stoner-byte/dsh-hide-brand) 去品牌行实现**：沿用上游 `logoRow` 类名片段和一次性样式注入思路，增加 Fold 自己的设置、macOS 限定及节点所有权清理；不捆绑或依赖整套上游插件，来源与 MIT 许可见 [第三方声明](THIRD_PARTY_NOTICES.md)。若同时启用原版 dsh-hide-brand，其常驻样式仍会隐藏 Logo，Fold 单独关闭开关无法让 Logo 显示回来。其他平台的品牌行可能有交互控件，Fold 不隐藏；真实 DSH GUI 的新版布局与显隐仍需现场验收。

## 兼容与边界

- DSH 0.2.1-rc.5 与 0.2.2-rc.1 的 `sidebar.workspaces` 都是只能渲染一个占用者的官方 slot。插件只在活动／收藏临时注册自己的替代视图，原生工作区节点不移走、不删除；开关关闭时注销自己的 slot、DOM 和监听器。已验证原生项与第三方临时竞争时，仅在运行时撤出自身视图和控件，不保存关闭；原生注册簿暂时为空或宿主 region/footer 短暂缺失且自身栏完好时也只运行时撤出。宿主恢复且自身注册确认成为唯一优先占用者后才显示控件并恢复原选视图。宿主 slot／原生身份或插件栏 DOM 结构异常仍硬隔离：撤出自身并尝试将后台设置保存为关闭，须在设置页手动保存开启后重试，不触碰其他插件节点。原生注册者身份按两个已发布构建各自的明确结构校验；未知构建不猜测接管。
- 自动检测不能识别任意插件私有的全局 CSS 或恶意 DOM 修改，因此不声称与所有未来插件百分百无冲突；未知宿主结构默认展示原生工作区，不尝试强行接管。
- 活动按待处理、运行中、明确未读的完成项及最近会话排序；普通空闲不假装完成或出错。收藏取自 DSH 的 `pinnedSessionIds`；空白、归档和子代理会话不进入普通列表。点击会话委托 DSH 原生 `uiWorkspace.openSession`；rc.1 的会话菜单及归档由 DSH 原生处理，rc.5 兼容回退的归档仍委托 `uiWorkspace.archiveSession` 并以宿主快照为准。
- Host 配置 `workspaceViewsEnabled` 默认为 false，旧试用版 localStorage 中的 `on` 不会绕过它；Tab 选择仍仅存本浏览器本地。不会写入会话正文或工作区文件，导航折叠/顺序的旧本地键保持兼容。
- v0.4.3 的工作区三栏、v0.4.4 的悬停会话操作与 v0.4.5 的归档安全路径原本基于 DSH 0.2.1-rc.5 的已发布构建；v0.4.9 增加按 DSH 0.2.2-rc.1 原生结构制作的兼容回归，v0.4.10 在 rc.1 上复用原生会话菜单。rc.5 回退路径中运行中真实模型会话的归档仅经过模拟测试。其他 Host 版本或未知侧栏结构会安全保持原生工作区，不承诺与所有第三方私有 CSS/DOM 百分百无冲突。原全局导航折叠与置顶会话仍沿用本机现有偏好；升级不会清理用户数据。自动化测试不能替代新设置页和侧栏的真实宿主 GUI 验收。

开发验证：Node.js 20+ 运行 `npm ci --legacy-peer-deps && npm test`。jsdom、React 与 Schemastery 仅用于本仓测试；`@deepseek-ai/cordis` 是 DSH 宿主提供的 peer，不随 GitHub 安装包打入。
