# DSH 左侧全局面板折叠

适配 DeepSeek Harness `0.2.1-rc.2`。把侧栏「全局面板」所有当前和未来注册的导航项切换为一排可横向滚动的图标；再次点击箭头恢复原来的竖排。工作区和会话列表不变。选择保存在当前页面的 localStorage 中，禁用插件后恢复原有 DOM 与样式。

## 安装

在桌面端「插件 → 添加插件」中填写本仓库 Release 的 `.tgz` 文件下载后的**绝对路径**，安装并启用；也可填写本 GitHub 仓库 Git 地址。不要对桌面 profile 手工执行 `pnpm add` 或编辑配置。该插件无安装脚本、无新增运行时依赖。

## 验证

运行 `node --test test/*.test.js`。桌面端安装后，打开有面板项的页面：确认箭头切换、图标可点击、增减其他插件项后一起参与折叠、会话列表保持可用。测试使用已有相邻项目 `turn-file-actions-plugin/node_modules/jsdom`，不进入发布包。

**兼容性限制：** DSH 当前未提供「全局面板容器」专用扩展槽；该插件使用宿主 DOM 的 `panelList`/`panelRow` 等 CSS 模块类名片段，DSH 升级后需再次实测。仅匹配中英文界面的「全局面板」导航，不会改动其他导航区域。
