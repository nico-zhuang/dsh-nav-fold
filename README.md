## 安装与升级

**公开正式版（v0.4.5）：**从 [v0.4.5 GitHub Release](https://github.com/nico-zhuang/dsh-nav-fold/releases/tag/v0.4.5) 下载 `dsh-nav-fold-0.4.5.tgz`，或用 DSH CLI 安装：

```sh
dsh plugin add https://github.com/nico-zhuang/dsh-nav-fold/releases/download/v0.4.5/dsh-nav-fold-0.4.5.tgz
```

**本地正式候选（v0.4.6，未发布）：**本分支的 `artifacts/dsh-nav-fold-0.4.6.tgz` 仅在完成本机主 GUI 重启后实测、另一设备模式切换与最终复核之后才可作为 GitHub Release 与市场更新的安装来源；当前不提供公开下载链接。preview.1 真实 GUI 失败、preview.2 严格错名安全审查失败，两份旧包不得安装交付；preview.3 是已通过匿名环境测试但仍待完整跨设备验收的开发预览。正式安装或升级后须正常重启 DSH；工作区三栏依旧**默认关闭**，需在插件配置中主动保存开启。市场现有条目仍指向 v0.4.5，更新 PR 不得先指向不存在的 0.4.6 Release 包。

## 交互，刚好够用

- **点一下**：展开或收起。图标与细线从当前位置平滑移动，连续点击也能立即反向。
- **停一下**：面板名称直接替换细线中央的箭头；移开后箭头回来。键盘聚焦图标时同样能看到名称，不必等待原生提示。
- **拖一下**：把常用图标移到顺手的位置，顺序保存在本机。也可以聚焦图标后按 `Alt + 方向键` 排序。

侧栏变宽或变窄时，图标由原生布局即时等距重排、自动换行；末行沿左侧列位对齐。点击展开或收起时仍有可中断的平滑动画，箭头低调呼吸，细线纤细淡出；系统选择「减少动态效果」时，移动与呼吸动画自动停止。新增的面板也会加入，不影响工作区和会话。

## v0.4.3 新增：工作区／活动／收藏（默认关闭）

启用路径：**插件 → 已安装 → dsh-nav-fold → 配置 → 勾选「启用工作区、活动与收藏三栏」→ 保存**。仅安装插件、点侧栏按钮或旧版浏览器偏好都不会替你打开三栏；配置尚未保存时仍显示 DSH 原生工作区。开启后，工作区沿用原生树，活动展示待处理／运行／近期会话，收藏读取 DSH 自身的置顶会话，不另建收藏数据。点击栏目不会切换当前打开的会话。重新关闭并保存后，插件的三栏和替代视图一起撤出，原生工作区立即回来。

三个 15px 线性图标居于侧栏中轴，收藏采用轻微斜置的 Pin；横框右侧另有不抢眼的折叠按钮，左侧留同宽空位，折叠后仅保留当前栏目标记与展开箭头。**折叠只是本浏览器的显示偏好**：不关闭活动／收藏视图，也不更改配置页的启用状态。可用鼠标或键盘操作；减少动态效果时停止过渡。

### v0.4.4 新增：会话悬停操作

活动和收藏会话行在鼠标悬停或键盘聚焦时显示三点菜单与 Pin 按钮；触屏不依赖悬停。Pin 直接调用 DSH 的 `uiWorkspace.pinSession/unpinSession`，改动的是原生置顶列表，不另存一套收藏数据；失败会提示重试且不虚报成功。三点按钮使用 DSH 自带菜单组件，仅提供**打开会话、收藏／取消收藏、复制会话 ID（剪贴板可用时）**；由于树状区的完整右键菜单不提供公开开启接口，v0.4.4 当时不冒充完整的原生右键菜单，未加入重命名／归档／分叉。

### v0.4.5 新增：安全归档活动与收藏会话

活动和收藏行增加独立归档按钮，三点菜单也提供归档；两者均调用 DSH 原生 `uiWorkspace.archiveSession`，不跳转、不直接改写会话文件或自建归档状态。请求成功后仍等待宿主更新 `archivedSessionIds` 才移除行，不提前假装归档成功。请求中阻止重复提交及并发 Pin；普通失败保留会话并提示重试。

如果宿主明确拒绝归档运行中的会话，才显示「归档并停止」确认；取消不停止任务，确认后才调用 `archiveSession(id, { stopActivity: true })`。确认失败时保留弹窗及错误提示供重试；缺失归档 API 时按钮不可用，不猜测其他停止或删除路径。**此运行中路径仅经过模拟测试，未用真实模型密钥或真实运行任务验收。**

## 兼容与边界

- rc.5 的 `sidebar.workspaces` 是只能渲染一个占用者的官方 slot。插件只在活动／收藏临时注册自己的替代视图，原生工作区节点不移走、不删除；开关关闭时注销自己的 slot、DOM 和监听器。已验证原生项与第三方临时竞争时，仅在运行时撤出自身视图和控件，不保存关闭；原生注册簿暂时为空或宿主 region/footer 短暂缺失且自身栏完好时也只运行时撤出。宿主恢复且自身注册确认成为唯一优先占用者后才显示控件并恢复原选视图。宿主 slot／原生身份或插件栏 DOM 结构异常仍硬隔离：撤出自身并尝试将后台设置保存为关闭，须在设置页手动保存开启后重试，不触碰其他插件节点。原生注册者身份按本机 rc.5 已发布构建校验；构建变化造成不匹配时不猜测接管。
- 自动检测不能识别任意插件私有的全局 CSS 或恶意 DOM 修改，因此不声称与所有未来插件百分百无冲突；未知宿主结构默认展示原生工作区，不尝试强行接管。
- 活动按待处理、运行中、明确未读的完成项及最近会话排序；普通空闲不假装完成或出错。收藏取自 DSH 的 `pinnedSessionIds`；空白、归档和子代理会话不进入普通列表。点击会话委托 DSH 原生 `uiWorkspace.openSession`；v0.4.5 的归档操作委托 `uiWorkspace.archiveSession`，以宿主归档快照为准。
- Host 配置 `workspaceViewsEnabled` 默认为 false，旧试用版 localStorage 中的 `on` 不会绕过它；Tab 选择仍仅存本浏览器本地。不会写入会话正文或工作区文件，导航折叠/顺序的旧本地键保持兼容。
- v0.4.3 的工作区三栏、v0.4.4 的悬停会话操作与 v0.4.5 的归档安全路径基于 DSH 0.2.1-rc.5 的已发布构建、匿名独立宿主及自动化测试验证；运行中真实模型会话的归档路径仅经过模拟测试。其他 Host 版本或未知侧栏结构会安全保持原生工作区，不承诺与所有第三方私有 CSS/DOM 百分百兼容。原全局导航折叠与置顶会话仍沿用本机现有偏好；升级不会清理用户数据。旧的匿名互动试验稿不能替代新设置页的真实宿主验收。

开发验证：Node.js 20+ 运行 `npm ci --legacy-peer-deps && npm test`。jsdom、React 与 Schemastery 仅用于本仓测试；`@deepseek-ai/cordis` 是 DSH 宿主提供的 peer，不随 GitHub 安装包打入。
