# dsh-nav-fold · v0.4.16（正式版）

> 一条细线收起全局导航，把空间留给工作区与会话。工作区／活动／收藏按需开启；可配置快捷键先移动会话焦点，再整理或打开当前会话。macOS 还可独立隐藏顶部 Logo。

下方五组画面可单独阅读，每组围绕一个功能主题，展示具体操作与结果。**画面是虚构资料的独立匿名合成示意，不是实际 DSH 录屏、真实插件 GUI 验收或遥控器实拍。** 正式功能与安装说明仍以本页文字和 [v0.4.16 发布说明](docs/releases/v0.4.16.md)为准。

## 安装与升级

**v0.4.16 安装：** 从 [GitHub Release](https://github.com/nico-zhuang/dsh-nav-fold/releases/tag/v0.4.16) 下载 `dsh-nav-fold-0.4.16.tgz`，或通过 DSH CLI 安装（`desktop` 换成你的 profile 名）：

```sh
dsh plugin --profile desktop add https://github.com/nico-zhuang/dsh-nav-fold/releases/download/v0.4.16/dsh-nav-fold-0.4.16.tgz
```

已针对 **DSH 0.2.1-rc.5 与 0.2.2-rc.1** 两个已发布构建核对原生侧栏结构并做自动化回归；不代表 0.2.1 的所有子版本均已验证。升级后正常重启 DSH；三栏依旧**默认关闭**，若旧版安全隔离曾将其保存为关闭，需在插件配置中重新保存开启。上一公开版 [v0.4.15](https://github.com/nico-zhuang/dsh-nav-fold/releases/tag/v0.4.15) 保留下载与重装回退入口；这仍是 GitHub Release `.tgz` 发布，不是 npm 包发布。

### 活跃整理：只操作明确聚焦的一行

先让「活动」中的会话主按钮获得键盘焦点，再通过**用户自行绑定**的整理快捷键打开**该行自己的**菜单；选择「固定在顶部」后，它进入独立顶部分组，钴蓝色标成为左侧 3px 细条。顶部固定不等于 DSH 原生置顶，也不会把会话加入收藏。rc.1 使用 Fold 独立整理入口、不点宿主三点；rc.5 使用 Fold 自有的兼容菜单。

**v0.4.15 整理菜单：** 无色＋五个原有冷色色标现在六格横排，不新增色数。自定义颜色保存后，底行左侧可单独「使用自定义颜色」，右侧独立铅笔按钮才打开 HEX 编辑器；未保存自定义色时底行显示「自定义颜色…」。左右键在六色间环绕，上下键分别去免打扰／自定义入口，末色按 Tab 也能到自定义入口；编辑按钮另有可读名称。Quiet 活跃行保持单行标题与小月亮；v0.4.16 中相邻 Quiet 各有独立的柔和行底，而非旧版连成视觉组。其它 Tab 保留原两行会话标题。

## 左侧栏优化，按需开启

<details><summary>查看设置路径、快捷键与旧版兼容说明</summary>

设置在 **插件 → 已安装 → dsh-nav-fold → 配置**，按用途分为两组；三个开关各自保存，不相互替代。v0.4.14 新增「活跃整理」原生快捷键，配置页也实时显示两项快捷键的绑定状态：

- **浏览与导航**：开启并保存「工作区／活动／收藏三栏」，再确认「会话焦点导航」已开启。到 **DSH 设置 → 快捷键**，分别给「会话导航 / Navigate sessions」和「活跃整理 / Organize focused Activity session」绑定组合键（两者均无预设）。进入导航后 ↑↓移动焦点，←→切换三栏；Enter 展开文件夹或打开会话，Esc 退出。活跃整理仅在「活动」栏中某个会话行明确获得键盘焦点时打开该行自己的整理菜单；没有焦点、处于其他栏或整理按钮不可用时不执行，不会按选中会话猜测。DSH rc.1 打开独立整理菜单，不会打开宿主原生三点菜单；rc.5 打开本插件自有的会话操作菜单，其中包含同样的活跃整理项。插件配置页从 DSH 原生快捷键目录实时显示两项绑定状态和键位；绑定和修改仍须前往 DSH 设置 → 快捷键，插件不自建录制器或写入快捷键配置。需要遥控器时，可在「无线麦」中把小米蓝牙遥控器的“进入列表”按键映射到导航组合键；Fold 不负责设备配对。

## 交互，刚好够用

- **点一下**：展开或收起。图标与细线从当前位置平滑移动，连续点击也能立即反向。
- **停一下**：面板名称直接替换细线中央的箭头；移开后箭头回来。键盘聚焦图标时同样能看到名称，不必等待原生提示。
- **拖一下**：把常用图标移到顺手的位置，顺序保存在本机。也可以聚焦图标后按 `Alt + 方向键` 排序。

侧栏变宽或变窄时，图标由原生布局即时等距重排、自动换行；末行沿左侧列位对齐。点击展开或收起时仍有可中断的平滑动画，箭头低调呼吸，细线纤细淡出；系统选择「减少动态效果」时，移动与呼吸动画自动停止。新增的面板也会加入，不影响工作区和会话。

## v0.4.3 新增：工作区／活动／收藏（默认关闭）

### 活跃列表专属整理（v0.4.13）

**v0.4.13** 在「活跃」提供「固定在顶部／取消顶部固定」、五种手动色标和「免打扰」。顶部固定的行在「顶部固定」分组标题下遵循本轮优先级排列，普通行留在分隔线后；没有顶部行就没有空分组。它只改变活跃列表的排序及近期 20 条上限，不等于 DSH 原生「置顶会话」，也不会加入「收藏」。整理菜单在文字右侧用向上箭头／小月亮区分两种动作，六个色标按钮按两行三列摆放（无色、青蓝、钴蓝／靛蓝、雾紫、银灰），点已选颜色可清除；人工色标避开任务状态使用的红、黄、绿。3px 左侧色条上下各留 4px，亮色主题使用更饱和的冷色，深色主题用柔和的对应色；Quiet 行色条仍可辨。已有 Host v1 色标槽位与其它偏好不重写，preview.3 原安装包及其旧色彩表现可作为回滚入口。

完成未读（绿点）会话从活跃列表点开后，本轮浏览暂时保留它在原绿灯队列中的位置，真实已读状态与绿点立即更新，不会因为落到近期 20 条之外而突然消失；连续打开多条也按本轮原顺序保留。新审批、重新运行以及人工固定在顶部仍立即按真实状态排序；离开活跃列表再进入时按当前 Host 状态重排，并恢复近期上限。这个浏览期位置只在内存中，不更改通知或 Host 未读位。

免打扰只把该活跃行置灰并显示小月亮，仍留在原本位置，可直接打开或从行内菜单取消。它**不会停止任务，也不会关闭 DSH 通知或审批提醒**，收藏和宿主原生菜单保持不变，不再有顶部「免打扰管理」。活跃偏好保存在 DSH 当前 profile 的 Host 配置中，正常重启或 localhost 端口改变后可从该 profile 恢复；不会跨设备同步。旧版浏览器缓存没有 profile 标识，**不会自动导入**：仅当 Host 尚未初始化且当前端口能读到旧缓存时，活跃列表末尾会提示「导入旧偏好」及跨配置风险；确认该缓存属于当前 profile 后才点导入。导入成功后不再重复提示，旧缓存仍保留以便回滚；旧端口不可访问的数据无法自动找回。不开启三栏时功能不露出；v0.4.13 已做自动化与合成 220/320px 深浅主题测试，**真实已登录 DSH GUI 点击与视觉验收仍待完成**，不把模拟样张当成已认证现场截图。

### v0.4.5 历史兼容路径：DSH 0.2.1-rc.5 的活动与收藏会话归档

以下仅描述 DSH 0.2.1-rc.5 的旧版回退行为：活动和收藏行有独立归档按钮，三点菜单也提供归档；两者均调用 DSH 原生 `uiWorkspace.archiveSession`，不跳转、不直接改写会话文件或自建归档状态。请求成功后仍等待宿主更新 `archivedSessionIds` 才移除行，不提前假装归档成功。请求中阻止重复提交及并发 Pin；普通失败保留会话并提示重试。

### v0.4.7：快捷键驱动的会话焦点导航

Fold 不直接连接蓝牙设备，而是使用 DSH 已有快捷键：在 **插件 → 已安装 → dsh-nav-fold → 配置** 保存启用「工作区／活动／收藏三栏」并确认「会话焦点导航」开关已启用，再到 **DSH 设置 → 快捷键 → 会话导航 / Navigate sessions** 自行分配入口组合键；将小米蓝牙遥控器通过「无线麦」的“进入列表”按键映射到该组合键。Fold 没有预设快捷键，不修改「无线麦」或遥控器配置；绑定前检查 DSH 已注册命令冲突，并留意其他插件自行监听的全局按键。

进入导航后，↑↓移动当前栏中可见文件夹或会话的真实键盘焦点，**不会自动打开会话**；←→切换「工作区／活动／收藏」；Enter 在会话上才打开它，在工作区原生文件夹上则调用宿主原有点击来展开／收起并保留导航焦点；Esc 退出并尽可能回到进入前的焦点。折叠文件夹的隐藏子项不会进入遍历。编辑框、弹窗以及 DS-Bot 占用侧栏时不抢走方向键；原有 `Alt + 方向键` 面板排序不受影响。关闭会话导航开关会退出焦点模式；导航命令继续注册以便在 DSH 原生快捷键页保留和编辑绑定，但其 resolve 返回 pass、不执行导航。三栏和用户在 DSH 中的快捷键绑定保留。实体小米遥控器与当前 DSH GUI 的整套组合操作仍需维护者亲测。

### v0.4.7：通栏三栏与节省空间的去 Logo 开关

三个 Tab 不再有右侧隐藏按钮，也不读取旧版的“折叠 Tab”本地偏好；启用三栏后保持可见，沿用原生侧栏内容宽度，与「新会话」约等宽。侧栏自身折叠成 rail 时仍由 DSH 原生布局隐藏三栏。上面的 v0.4.3 截图是历史示例，**不代表当前通栏样式**。

「隐藏顶部 Logo」是 Fold 中独立保存的开关，默认关闭，**无需开启三栏也能使用**。Fold 在 macOS 仅隐藏顶部纯展示的鲸鱼／字标行，让「新会话」上移，为会话列表留出空间；关闭开关或停用 Fold 后移除自身样式。该功能**收录并适配 [stoner-byte 的 dsh-hide-brand](https://github.com/stoner-byte/dsh-hide-brand) 去品牌行实现**：沿用上游 `logoRow` 类名片段和一次性样式注入思路，增加 Fold 自己的设置、macOS 限定及节点所有权清理；不捆绑或依赖整套上游插件，来源与 MIT 许可见 [第三方声明](THIRD_PARTY_NOTICES.md)。若同时启用原版 dsh-hide-brand，其常驻样式仍会隐藏 Logo，Fold 单独关闭开关无法让 Logo 显示回来。其他平台的品牌行可能有交互控件，Fold 不隐藏；真实 DSH GUI 的新版布局与显隐仍需现场验收。

## 兼容与边界

- DSH 0.2.1-rc.5 与 0.2.2-rc.1 的 `sidebar.workspaces` 都是只能渲染一个占用者的官方 slot。插件只在活动／收藏临时注册自己的替代视图，原生工作区节点不移走、不删除；开关关闭时注销自己的 slot、DOM 和监听器。已验证原生项与第三方临时竞争时，仅在运行时撤出自身视图和控件，不保存关闭；原生注册簿暂时为空或宿主 region/footer 短暂缺失且自身栏完好时也只运行时撤出。宿主恢复且自身注册确认成为唯一优先占用者后才显示控件并恢复原选视图。宿主 slot／原生身份或插件栏 DOM 结构异常仍硬隔离：撤出自身并尝试将后台设置保存为关闭，须在设置页手动保存开启后重试，不触碰其他插件节点。原生注册者身份按两个已发布构建各自的明确结构校验；未知构建不猜测接管。
- 自动检测不能识别任意插件私有的全局 CSS 或恶意 DOM 修改，因此不声称与所有未来插件百分百无冲突；未知宿主结构默认展示原生工作区，不尝试强行接管。
- 活动按待处理、运行中、明确未读的完成项及最近会话排序；普通空闲不假装完成或出错。收藏取自 DSH 的 `pinnedSessionIds`；空白、归档和子代理会话不进入普通列表。点击会话委托 DSH 原生 `uiWorkspace.openSession`；rc.1 的会话菜单及归档由 DSH 原生处理，rc.5 兼容回退的归档仍委托 `uiWorkspace.archiveSession` 并以宿主快照为准。
- Host 配置 `workspaceViewsEnabled` 默认为 false，旧试用版 localStorage 中的 `on` 不会绕过它；Tab 选择仍仅存本浏览器本地。不会写入会话正文或工作区文件，导航折叠/顺序的旧本地键保持兼容。
- v0.4.3 的工作区三栏、v0.4.4 的悬停会话操作与 v0.4.5 的归档安全路径原本基于 DSH 0.2.1-rc.5 的已发布构建；v0.4.9 增加按 DSH 0.2.2-rc.1 原生结构制作的兼容回归，v0.4.10 在 rc.1 上复用原生会话菜单。rc.5 回退路径中运行中真实模型会话的归档仅经过模拟测试。其他 Host 版本或未知侧栏结构会安全保持原生工作区，不承诺与所有第三方私有 CSS/DOM 百分百无冲突。原全局导航折叠与置顶会话仍沿用本机现有偏好；升级不会清理用户数据。自动化测试不能替代新设置页和侧栏的真实宿主 GUI 验收。

开发验证：Node.js 20+ 运行 `npm ci --legacy-peer-deps && npm test`。jsdom、React 与 Schemastery 仅用于本仓测试；`@deepseek-ai/cordis` 是 DSH 宿主提供的 peer，不随 GitHub 安装包打入。
