# DSH 左侧全局面板折叠

适配 DeepSeek Harness `0.2.1-rc.2`。全局面板导航顶部是一条无框细线，中央小箭头切换展开/折叠；折叠后图标随侧栏宽度自动换行，不再横向滚动。悬停图标显示宿主当前语言的面板名称（如「插件」「记忆系统」）。按住图标可拖动排序，目标位置有蓝色高光提示，松手后保存；键盘也可用 `Alt + 方向键` 调整。新注册的面板会自动加入，工作区与会话列表不受影响。

## 安装

在桌面端「插件 → 添加插件」中填写本仓库 Release 的 `.tgz` 文件下载后的**绝对路径**，安装并启用；也可填写本 GitHub 仓库 Git 地址。不要对桌面 profile 手工执行 `pnpm add` 或编辑配置。该插件无安装脚本、无新增运行时依赖。

## 验证

运行 `node --test test/*.test.js`。桌面端安装后确认切换、悬停名称、图标拖动和高光提示、重新打开后顺序保留，以及新增插件面板和工作区/会话可用。测试使用已有相邻项目 `turn-file-actions-plugin/node_modules/jsdom`，不进入发布包。

排序只保存在当前设备浏览器的 localStorage，不跨设备同步；目前以面板显示名称识别项目，重名或改名（包括切换语言）后可能恢复默认顺序。禁用插件会撤销注入的样式、事件和 DOM 属性。DSH 当前没有全局面板专用扩展槽，本插件匹配宿主 `panelList`/`panelRow` 类名片段，DSH 升级后需重测。仅作用于中英文「全局面板」，不修改其他导航区域。
