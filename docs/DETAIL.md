## dsh-nav-fold

A compact sidebar workspace for DSH.

### What it adds

- Foldable global navigation.
- Workspace, Activity, and Favorites views.
- Activity ordering, drag organization, and per-session actions.
- Configurable focus navigation and Activity organization shortcuts.
- Optional macOS logo-row hiding.

Settings apply to the current profile. Activity preferences remain local to that profile and are never written into the Host session order automatically.

Use **More settings…** from the sidebar Tab or fold control to open the plugin settings.
