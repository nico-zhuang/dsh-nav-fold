# Fold 通栏三栏与顶部品牌开关设计

状态：用户确认“继续”；在 `feat/fold-remote-navigation` 独立工作树实现试用版，不合并、不发布。

## 目标和可见行为

1. 保存开启“工作区／活动／收藏”后，三个图标 Tab 一直显示。移除 Tab 行右侧的展开／隐藏按钮以及为了居中而空出的左侧轨道。Tab 背景框横向填满与顶部“新会话”同一侧栏内容区域（沿用当前侧栏的左右 12px 外边距），三按钮仍等宽，当前栏高亮和焦点轮廓不变。保留原生侧栏收起成 rail 时隐藏整条 Tab 行的既有行为；它不是被删除的 Tab 专属隐藏按钮。
2. DSH 插件配置增加独立的“隐藏顶部品牌 Logo”布尔设置，默认关闭；独立保存，与三栏开关互不依赖。保存开启后仅隐藏 DSH 侧栏顶部品牌整行，让“新会话”自然上移、不留白。保存关闭、插件停用或卸载则移除自己注入的规则，Logo 原样回来。缺少配置快照或不可写时保持默认显示，不因暂时不可用猜测用户意图。
3. 旧本地键 `dsh-nav-fold:workspace-tabs-collapsed` 不再读取或写入；不清理用户存储。升级后原先隐藏的 Tab 也显示，且三栏开关状态保持原值。遥控导航、Alt+方向键排序、Activity/Favorites 会话操作及 DS-Bot slot 冲突安全撤出不受影响。

## 架构和兼容边界

- 在 Fold 自身 Host `Config` 里增加 `hideBrandEnabled`，用现有 `configForms.get('nav-fold')` 渲染独立可保存的设置控件。浏览器半区只在配置确认为 true 时注入一个作用于 `.kB3qhq_root [class*="logoRow"]` 的样式节点；不用跨插件 API，不安装或停用同事插件，不修改宿主 DOM/会话。若日后独立 `dsh-hide-brand` 同时启用，其常驻 CSS 将使 Fold 的关闭开关无法恢复 Logo，应避免双装并在文档说明。
- [同事仓库](https://github.com/stoner-byte/dsh-hide-brand) 的 package.json 声明 MIT，但仓库元数据无独立许可证文件；这里只复用它验证过的**技术思路**（品牌 slot 清空仍有 fallback、稳定的 `logoRow` 类名片段），独立写一条限制到 DSH sidebar root 的 CSS 规则，不复制其插件文件，文档注明来源。适配当前 DSH 0.2.1-rc.5；宿主类名变化时不猜测其他节点。
- 三栏仍由当前 `sidebar.workspaces` 单 slot 协调。完整性检查从“恰有 Tab 与外侧按钮两个子节点”改为“恰有 Tab 一个子节点”。真正的 Tab 丢失、未知竞争者及结构变化仍按既有隔离逻辑安全撤出；不能因为删除旧按钮而把保存的三栏配置错误地写为 false。

## 验收

- 测试先红后绿：既有 93 项基线；新增通栏结构、迁移旧折叠偏好、Tab 点击/键盘导航、原生 slot 保留、真正的 Tab 损坏仍隔离；品牌默认显示／独立开关保存／保存失败重试／三栏关闭也生效／卸载恢复／DS-Bot 临时占位期间 Logo 开关独立等覆盖。
- 运行语法检查、全套测试、打包和差异检查；与已安装 preview.2 分离编号并保留 rollback 包。本机试装后检查配置 schema 与 live slot；真实 GUI 宽度、Logo 显隐和遥控器实测未取得证据时不得声称完成。
