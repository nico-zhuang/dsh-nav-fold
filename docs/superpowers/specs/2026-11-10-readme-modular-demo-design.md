# dsh-nav-fold v0.4.14 README 分步介绍设计

状态：用户确认可按步骤单独说明，不强制连贯成片；在独立 `feat/readme-modular-demo-v0414` 分支制作候选稿。正式 v0.4.14 插件代码、安装包、已有 GIF/MP4、线上 README 均不覆盖。

## 目的与受众

让第一次看到仓库的 DSH 用户在 README 首屏读懂：Fold 只收起全局导航；工作区／活动／收藏须主动启用；焦点导航与活跃整理分别由用户自行绑定快捷键；活跃顶部固定、冷色色标、Quiet 仅属于活跃视图；macOS 去 Logo 是独立设置。读者可以从任意一步进入，不必看完一段连续片。合成演示不是已登录 DSH 现场验收、实体遥控器实拍或默认键位证明。

## 结构与介质

沿用真实插件的颜色、Tab SVG、细线、24px 操作目标及会话层级，以固定虚构项目／会话制作统一视觉语言的五个**独立小节**。每节包含短标题、单一动作、肉眼可见的前后变化、最多一句边界说明；不以孤立的大字标题卡充当交互。优先使用静态前／后对照和少数 3–6 秒短循环动图，让 README 不同时加载五个大 GIF；各节的可读静态封面独立保存，高分辨率 MP4 可选作为深度查看入口，不强求完整长片。首屏先给品牌定位、简洁目录和一处主视觉，再按步骤展开。移动端窄版中图片与文案垂直排，GIF 关帧仍能读懂，尊重减少动态效果。

五步的动作与结果：

1. **收起全局导航**：点击细线，六个全局入口收成图标并可悬停即时显名；新会话、工作区与会话不消失。
2. **按需开启三栏**：初始开关为关，用户保存后出现工作区／活动／收藏三个真实 SVG Tab；切换 Tab 不自动打开会话，未知宿主结构保留原生工作区。
3. **只整理当前聚焦的活跃行**：先给一个活跃会话主按钮可见键盘焦点，再显示“用户自行绑定的示例组合键”触发该行自己的菜单；点「固定在顶部」后行进入独立顶部分组，选冷色色标后显示 3px 条。另示 Quiet 视觉变淡／月亮而运行蓝点仍在；不暗示通知、审批或任务被静音。rc.1 的独立整理菜单不点宿主原生三点；rc.5 的 Fold 兼容操作菜单包含整理项。
4. **导航与遥控器映射**：展示入口快捷键（无预设）→ ↑↓ 移动真实焦点、←→ 切栏目、Enter 才打开聚焦会话或展开原生文件夹；无焦点／弹窗／终端不触发整理。小米蓝牙遥控器只作为“可经无线麦映射”的可见示意，不表现真实配对或实体实拍。插件配置页的两项绑定状态来自 DSH 目录，编辑始终去 DSH 设置 → 快捷键。
5. **macOS 独立隐藏 Logo**：在三栏关闭的情况下另存该开关，仅隐藏 macOS 顶部展示品牌行，新会话上移；不表示其他系统通用，且与工作区三栏不互为条件。

## 证据与真实性

素材统一显著标注“独立匿名合成 · 虚构会话与界面 · 非真实 DSH 录屏；遥控器未实拍”。不得使用用户原录屏、真实账户、会话标题、密钥或当前 DSH profile。脚本中的示例按键必须显著写“用户自行绑定的示例组合键”，因为两个命令均 `defaults: {}`；不能给出看似系统默认的快捷键。新素材不替换现有 `docs/images/demo.gif` 或 v0.4.1 视频链接，除非所有画面逐步验证、体积/移动端可读性核实并取得用户对内容的明确采纳；源码、Host 设置、安装包不随宣传素材修改。
