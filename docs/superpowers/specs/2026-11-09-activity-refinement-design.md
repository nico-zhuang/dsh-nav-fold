# 活跃列表整理·第二轮修订设计（用户已选择 A）

本修订覆盖同目录《2026-11-09-activity-personalization-design.md》中关于免打扰排序/顶部管理、短色条和 browser-only 存储的旧约定。仅作用于 dsh-nav-fold 的「活跃」视图；收藏、原生右键/三点、原生收藏图钉、系统通知/审批、真实运行状态和文件夹均不改。当前安装版 preview.2 在完成验证并打新版本前保持不动。

## 行与菜单

- 色标采用用户选定的 A：固定色板，左侧 3px 竖条、距离行顶和行底各 4px，圆角约 2px，不侵入标题和状态点，不影响 45px 行高；任何带色标的活跃行都显示，不只当前选中项。标记保留文字可访问名称；不会在收藏里出现。菜单里点击**当前已选颜色**等同选「无色」，两者都删除 color 偏好；点其他颜色则切换。不接受任意 CSS 色值。
- 免打扰不再产生顶部「免打扰管理」或额外列表。该行仍按其真实状态参与原有活跃排序和近期上限，不再把 running/waiting 强制按 recent 排、不因免打扰本身移出列表；独立活跃置顶优先。行背景/文字适度灰化以示低关注，但它仍可点击、聚焦、打开和在整理菜单里取消免打扰，不使用 disabled 样式。副标题右侧显示可辨识的小月亮，取代该行原活动状态点；语义名称需明确「仅活跃列表免打扰」，不能暗示通知已关闭或任务暂停。实际状态及通知/审批完全不变。
- 整理按钮与宿主原生三点继续并列，Host 原生右键/Shift+F10 钩子保持原样；键盘焦点轮廓、触屏显示和低动态偏好延用现有规则。

## 可跨端口恢复的本机存储

- 当前 `window.localStorage['dsh-nav-fold:activity-preferences']` 按完整浏览器 origin（含随机端口）隔离，重启后未必可读。改用现有 `ctx.configForms.get('nav-fold')` 的 Host-backed form，插件配置新增可写 `.volatile()` 的 `activityPreferences` 字段，保存 `{"version":1,"sessions":{...}}`。安装版 DSH 0.2.2-rc.1 官方 settings/client-ui-settings 文档说明 volatile form 的写入持久化至 active profile Cordis patch，`set` 写入有序并返回成功/失败；Host profile 同一设备内跨端口共享。此字段只存 session ID 与 top/quiet/color，不存标题、会话消息、路径或系统状态；不跨设备同步。
- 配置不就绪/不可写不能报告“已保存”；保存时先验证结构、固定色板、ID 与限制（读取字符串最多 200KB、最多 1000 项），序列化交互以免两次快速更改以旧快照覆盖新值。UI 可即时响应，但 Host 拒绝写入时恢复最近一次已保存值并显示易懂的失败信息；禁用/启用插件后从 Host 配置恢复。已有 `workspaceViewsEnabled`、`navigationEnabled`、`hideBrandEnabled` 与原生收藏设置不受写入影响。只在用户更改或必要的单次迁移时写入，不在每次渲染时写。
- 首次 Host 字段为空且当前 origin 仍能读到旧版 localStorage 时，验证旧格式后迁移一次；**先 Host 写成功，才清理当前 origin 的旧键**，防止清除全部偏好后旧数据复活。Host 有数据时永远优先，不用旧浏览器缓存覆盖。旧端口已不可访问的值不能假称自动找回，须如实说明。跨 profile、换设备以及清除 DSH profile 不是本轮同步需求。
- 控制写入大小与频率；如果 Host 配置表单验证拒绝这一字段或实测会导致不安全的配置重载，不退回不可靠的 browser-only 持久化或私自写 Host 文件，应停下并说明阻断原因。

## 验证与交付门槛

1. 先新增 RED 回归：同色复选清除、A 色条满行但不增加行高、免打扰置灰及月亮并撤除顶部管理、Quiet 保留真实排序/上限、收藏/宿主菜单/通知隔离。
2. 再新增 RED 持久化回归：两个不同浏览器 origin（代表不同 localhost 端口）共用同一 Host form；旧 localStorage 只在当前 origin 迁移且不覆盖 Host；异步写入失败和快速连续操作不丢数据；禁用再启用从 Host 恢复。
3. 修复后跑全量测试、源文件语法/差异检查，在匿名 220/320px 狭窄视图目检普通、色标、置灰、置顶、选中、焦点和触屏状态；不能把匿名预览冒称已登录 DSH 真实 GUI。
4. 制作不复用 preview.2 编号的独立本机预览包；先备份当前 desktop manifest/lock/preview.2，打包逐文件校验后离线安装、不强杀当前 DSH；建议用户正常重启做真实界面验收。无用户授权不发布公开版或合并主分支。
