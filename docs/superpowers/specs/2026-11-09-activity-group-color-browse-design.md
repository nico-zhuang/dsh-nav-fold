## 会话行和分组

有活跃顶部固定行时，在这批行前显示「顶部固定 / Kept at top」小组标题，细线分开普通队列；分组语义用可读的标题标识。没有顶部固定行时不留空标题或分隔线；仅有顶部行时不显示多余尾分隔线。固定组与免打扰不是同一个概念：顶部+免打扰会话仍在固定组中，原行保持置灰/月亮/色条，普通免打扰会话依旧留在自己位置，不增设免打扰管理区。原生收藏依旧不受影响。菜单保持「固定在顶部／取消顶部固定」及右侧箭头，且新固定操作即时改变组别。

## 明晰冷色与回滚

原五个已持久化 color 值是可回滚的**槽位 ID**，不是新颜色名称：`green→青蓝`、`blue→钴蓝`、`violet→靛蓝`、`rose→雾紫`、`amber→银灰`。保留 `{"version":1,"sessions":...}` 与这些键，避免新预览写入后回滚到 preview.3 时丢失 Host 顶部固定/免打扰/色标偏好；旧预览会显示其原色。新菜单按「无色／青蓝／钴蓝；靛蓝／雾紫／银灰」两行三列展示，视觉、悬停、读屏名称均为新色，不向用户显示旧槽位英文词。仍为每会话单个可清除色标。

深色五色：青蓝 `#72CADA`、钴蓝 `#80AFFF`、靛蓝 `#B09AFF`、雾紫 `#CF9CEB`、银灰 `#B2BAC8`；亮色饱和五色：青蓝 `#075E82`、钴蓝 `#0754BD`、靛蓝 `#532BBB`、雾紫 `#7F26A5`、银灰 `#49586C`。银灰故意保持中性，以便与四种高饱和冷色区分。3px 竖条继续上下各留 4px；Quiet 的背景/文字仍置灰，色条透明度由 .7 改为 .85，减少极细线在两主题下失去对比。由宿主**有效主题**（已有行前景色/Host token）决定用哪一套颜色，显式浅色设置优先于 OS 偏好；监听主题 DOM 属性和系统外观变化，不把 OS prefers-color-scheme 当作唯一真相。若宿主暴露的 computed 前景色不可解析，回退 CSS color-scheme / OS。所附静态样张只使用模拟背景，不算真实 DSH 双主题验收。

## 绿灯会话的浏览期保序

原始排序仍是 `top > waiting > running > completionUnread > recent`，同级按 updatedAt；近期上限 20。仅在用户**从活跃列表点开完成未读行**时，暂存其相对于本轮可见绿灯队列的初始位置。Host 将其改为 recent 后，真实 `kind` 与状态点立刻更新，但这一行在本轮活跃浏览中占原绿灯位置，不被最近 20 条限制隐藏；连续打开多条绿灯行都保留原先相对顺序，不重复定时跳动。新等待审批、运行中任务及用户主动“固定在顶部／取消顶部固定”立即按真实优先级响应；若暂存行后来再次进入 running/waiting，该旧保持失效。离开活跃 Tab（包括去收藏/工作区）再进时清除暂存，恢复当前 Host 排序和 20 条上限。暂存只在内存，不写 Host/浏览器、不更改真实未读位与通知。焦点和当前会话高亮维持 Host 行按钮语义；优先解决位置丢失，不以动效掩盖越界消失，减少动态效果不播放位移动效。
