# dsh-nav-fold：图标悬停、侧栏等距响应和分隔线动效

用户于 2026-10-20 确认按此方案实施。仅修改客户端导航交互，不触碰工作区、会话或排序持久化。

## 悬停名称

折叠时，图标 `pointerover` 或键盘 `focusin` 立即令底部分隔线中央的箭头让位于该图标当前 `aria-label`。图标间切换采用两个文字层约 90ms 交叉淡入淡出，零等待；离开所有图标后箭头复位。按钮保留原有 `aria-label` 和操作能力，文字只是视觉提示。折叠状态不再写入原生 `title`，避免浏览器延迟提示；展开或卸载时恢复宿主更新后的原始 `title`。语言或面板项动态变化时取最新 `aria-label`，长名称以省略号限制在分隔线宽度内。

## 等距伸缩

折叠项仍保持 36px 可点击宽度，列间距设为 0 并使用 `justify-content: space-evenly`；每一行的左右余白和图标之间保持相等，最后不足一行时居中。侧栏 ResizeObserver 读取布局变化，复用现有 WAAPI FLIP，从当前可见位置把图标接到新位置，短时缓动并容许连续拖动中断；主布局由浏览器实时决定，不以动画延迟布局。展开态维持宿主原布局，排序样式保持不变。

## 呼吸和渐隐

箭头在展开、折叠两态均做低幅缓慢透明度呼吸；悬停文字可见时暂停/隐藏箭头的呼吸。分隔线由 flex 两段组成，首尾用渐变遮罩消失，中央随标签宽度自然留空。`prefers-reduced-motion: reduce` 时停用呼吸、弹性位移，仅保留必要的短淡入淡出；不增加新依赖。

## 验证边界

JSDOM 测试原生 `title` 不再弹出、无延迟文字替换/恢复、键盘焦点、语言变化、等距 CSS、ResizeObserver 清理和低动态分支；在真实 Chromium 逐帧测量宽窄侧栏的图标位置与左右余白，检查连续拖拽缩放、快速跨图标悬停及禁用插件的还原。公开配图仅用现有虚拟示意页更新，不截取真实桌面信息。
