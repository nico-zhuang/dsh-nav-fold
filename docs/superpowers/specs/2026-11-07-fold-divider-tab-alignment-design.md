# Fold 分隔线与三栏宽度校准设计

用户对 v0.4.11 的暗色截图反馈：顶部间距可接受，但横线＋箭头在图标与 Tab 之间看起来偏下；三个 Tab 组成的轨道比宿主「新会话」按钮两边多宽一点。用户随后明确授权把分隔线调中，并使两者一样长。

## 视觉依据

截图中的新会话按钮可见高度约 76 图像像素，宿主 rc.1 的真实按钮是 38 CSS px；Tab 轨道可见高度约 62 图像像素，Fold 样式为 31 CSS px。因此截图是约 2× 像素采样。截图边缘约为按钮 x=62..574，Tab 轨道 x=54..582，相差每侧 8 图像像素，即约 4 CSS px。rc.1 宿主按钮 `margin-inline:calc(var(--dsh-sidebar-paint-inset) + 1px)`，root 的 paint-inset 是 3px；rc.5 按钮左右 margin 是 2px，没有 paint-inset 变量。两版的 Fold Tab 行都是 root 直属子节点；给 Fold Tab 行 `margin-inline:calc(var(--dsh-sidebar-paint-inset, 1px) + 1px)`，分别内缩 4px/2px，与各自宿主按钮一致，不直接改宿主按钮。

截图中箭头／横线的可见中心约 y=334，图标画面下缘约 y=288、Tab 轨道上缘约 y=359；它相对两者可见边缘的中点约偏下 10 图像像素，即 5 CSS px。移动整个 24px 箭头按钮会在无额外高度的窄侧栏及换行时侵入上一排 36px 图标命中区；给 Tab 加上边距则牺牲刚节省的会话高度。因此保持按钮的位置、24px 高度、上下空间和焦点轮廓不变，仅把按钮内部两段分隔线与箭头/悬浮标签一起向上移动 4 CSS px。14px 箭头上下总留白 10px，移动 4px 后顶部还剩 1px，仍在 24px 命中框内。移动只在 Fold 的折叠导航状态生效，展开状态保留原居中。

## 验收边界

不改新会话按钮、宿主样式、导航图标/Tab 各自点击范围、三栏选中颜色、动画时长、持久化、第三方入口或工作区 slot 安全机制。回归覆盖两版宿主间距规则、折叠/展开切换、窄宽与多行图标、悬浮标签及键盘焦点、鼠标操作、减少动态效果、宿主卸载恢复。客户端真实 GUI 若不能授权控制，只以自动行为回归和用户提供的已安装版本截图分别表述，不能将静态截图冒称新版本现场验收。正式交付独立 v0.4.12，v0.4.11 保留回退。
