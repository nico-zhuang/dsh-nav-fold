# Fold 侧栏优化合集设置页设计（v0.4.8）

## 决策与范围

用户已批准直接实施并发布，不再等待设置页人工检查。原 `dsh-nav-fold` 同名插件的已公开 v0.4.7 安装包与 Release 不可同号重打；本次使用独立正式版 v0.4.8，更新同仓库 main、安装包和 GitHub Release。当前独立浏览器访问 DSH GUI 需会话认证，未经现场验收不得声称已验证真实页面或实体遥控器。

## 信息结构

设置页沿用宿主字体、主题色与原有配置入口，仅在插件作用域内做紧凑排版，不另建页面或卡片墙。按用途分为「浏览与导航」和「空间整理」。前者先展示工作区／活动／收藏三栏，后展示依赖其已保存开启状态的会话导航；后者展示独立可用的隐藏顶部 Logo。每项采用同样的名称、简短用途、原生勾选框及本项保存按钮，保存失败在本项内提示并保留未保存选择；避免把三个开关混成一次非原子保存。

会话导航指南邻近自身开关：先开启并保存三栏；在 DSH 设置 → 快捷键绑定「会话导航 / Navigate sessions」的入口组合键（无预设）；可选在「无线麦」中把小米蓝牙遥控器进入列表按键映射到同一组合键。简明操作说明为 ↑↓移动可见文件夹／会话焦点，←→切换三栏，Enter 展开文件夹或打开会话，Esc 退出。明确并非插件直接连接蓝牙。

空间整理项写明仅 macOS、与三栏无关，并在选项旁标注「收录并适配 stoner-byte 的 dsh-hide-brand（MIT）」及上游链接；保留现有独立存储和 Fold 所有样式节点的清理，不要求安装上游原包。未来可按同一模块契约收录其他同事或第三方功能，不在本版加入尚不存在的模块、动态插件机制或新全局总开关。

## 行为和验证

保留 `workspaceViewsEnabled` 默认 false、`navigationEnabled` 默认 true、`hideBrandEnabled` 默认 false、三个独立 `form.set`、结构冲突硬隔离的明确重新启用、DS-Bot 临时让位和原生文件夹 Enter 行为。测试先行覆盖分组与位置、三步说明、来源署名、草稿独立/失败重试、安全重启以及主题 CSS 作用域；全套 Node 测试、语法、六文件清单、安装版与新包字节核对。仓库首页 README 首屏及 Release 介绍以自定义入口快捷键导航焦点为主，遥控器为可选映射示例，同时明确归属。v0.4.7 Release 与回退下载保持可用。
