# 活跃列表免打扰会话单行设计

## 已确认目标

用户已确认：仅在「活跃」Tab，已设为免打扰的会话行压缩为单行，显示会话标题及同一行的月亮标识，视觉上不显示工作区文件夹名称；其他会话行和其他 Tab 保持原样。若只隐藏工作区文字却保留第二行的占位，行高不会变短，因此需从 DOM 中省去该副行。单行仍须可辨认免打扰，并能通过现有整理菜单取消免打扰。

## 实现与边界

- 只改会话行渲染和对应 CSS，保持 `activityOnly && row.quiet` 的既有判定、背景弱化、3px 颜色标记、顶部固定分组、菜单、状态和 Host 偏好完全不变；不新增配置键，也不影响第一阶段自定义颜色。
- 仅免打扰的活跃会话以 `title-row` flex 同行摆放原有标题和原有月亮 SVG，预留现有操作按钮所需右侧空间；省去工作区副行以及不适用于免打扰的任务状态点。普通活跃会话继续标题＋工作区／状态的两行结构。收藏及工作区 Tab 的会话行不受活跃免打扰偏好影响。
- 按钮的 `aria-label` 继续包含标题、工作区及活跃免打扰状态；月亮维持可朗读名称与悬浮提示。标题仍可截断、鼠标／键盘点击继续打开原会话，整理菜单保持可操作。
- 用户追加确认连续免打扰行的底色应连成一个视觉组：若下一个相邻行也是 Quiet，当前行下方左右两角改为直角；若上一个相邻行也是 Quiet，当前行上方左右两角改为直角；单独一行仍保留四角圆角。顶部固定分组边界、普通行或分隔线会切断连续组，不跨越它们合并。仅调整边角，不改变每个会话独立的点击、焦点、颜色条和菜单。
- 本改动仅在已有 `feat/activity-custom-color-phase1` 功能分支另起提交；用户随后明确授权本机安装验收，因此只安装在新建的 `navfold-qa-20261111` 测试 profile，不覆盖现用 `web` profile 中的 v0.4.13；不推送、不修改 README 素材。QA profile 仍可读到本机共享的真实会话，验收时不打开或修改真实会话。真实 DSH GUI 验收必须标明准确 profile 和服务 URL。

## 验收

用 DOM 回归证明活跃 Quiet 行只有标题＋月亮、不含可见工作区副行，`aria-label` 仍含工作区；普通活跃行仍是两行；取消 Quiet 后恢复副行和原状态点；收藏／工作区行不继承紧凑样式。验证相邻 Quiet 首/中/尾行的内侧圆角为直角、外侧圆角保留，普通会话和顶部固定分隔线切断合并；单独 Quiet 行四角仍圆。原有可访问对比度与完整测试集通过。在 QA Web profile 的真实 DSH GUI 检查最窄侧栏实际行高、相邻边角、暗/亮主题与菜单悬浮状态；若因共享数据或 Host 权限无法安全执行某项，应注明未验收而非冒称通过。
