# 活跃列表专属整理设计（已由用户确认范围）

仅在 dsh-nav-fold v0.4.12 的「活跃」视图提供三项功能：独立置顶、手动色标、「免打扰」。不做文件夹，不更改原生图钉、收藏、工作区目录、真实会话运行/待审批状态或系统通知。用户明确批准「免打扰」只影响活跃列表的呈现：运行中的会话按普通近期项排序，受原有近期上限约束；不关闭通知或审批。

## 行为与数据

- 独立设置键 `dsh-nav-fold:activity-preferences`：版本 1，按 session id 存储 `top`（布尔）、`quiet`（布尔）和 `color`（固定色板标识，不接收任意 CSS），只存有自定义值的项；存储失败要保持当前会话交互但不伪称已永久保存。插件使用现有 localStorage 偏好机制：仅当前浏览器、本机，不跨设备同步；同源多窗口同时修改暂不提供跨窗口冲突合并，仅保证单窗口交互。损坏数据一律忽略；任何设置均不得调用 `uiWorkspace.pinSession/unpinSession`。
- 列表分区：活跃置顶在最上方，即使已超近期 20 条仍显示；其余待处理、运行、未读、近期依旧按原优先级及更新时间排列。免打扰把该行在活跃视图中的有效排序类型改为 `recent`，但保留真实类型，不停止运行；活动行不显示脉动状态点；超过近期上限后主列表不显示，但顶部常驻「免打扰管理（N）」可展开当前未归档 quiet 会话，提供打开与取消免打扰（管理入口不是文件夹，也不取消近期限制）。显式置顶优先于免打扰；归档/空白/子 agent 仍按原规则过滤。收藏列表不应用这三项偏好。
- UI：活跃行有独立「整理」菜单，包含置顶/取消置顶、免打扰/取消免打扰及单选色板/无色。原有原生会话菜单与图钉/收藏按钮行为保持不变。色标为行首细色条而不是运行状态灯，带可访问文字标签；色板用有限固定颜色及文字名，避免纯颜色传达含义；键盘可操作，缩窄时不压缩会话标题。为保护 0.2.2-rc.1 的原生 context menu，不复用或拦截其右键钩子，新增独立小控件。

## 验证

测试先行：模型排序/近期阈值、互相独立的置顶+免打扰、损坏/恶意持久化、仅活跃 UI、菜单键盘与原生菜单并存、刷新恢复、收藏及 Host 状态不变。全量 114 项基线通过（`npm ci --legacy-peer-deps`，因现有 lockfile 缺 Cordis peer 安装条目）。不得在用户正在使用的 desktop profile 自动安装或发布，候选独立 worktree 提供测试证据；如未做真实 GUI 明确标注。
