# Fold 浅选中态与紧凑顶部设计

## 批准范围

用户已批准：仅改 Fold 三栏 Tab 的选中底衬，以及已折叠全局导航图标、折叠箭头与三栏之间的留白。新会话按钮位置、底部多插件入口仅研究，不实施。本轮保留全部标签、排序、快捷键、会话菜单、持久化和安全隔离行为。

## 视觉判断

当前选中指示直接用 `--dsw-specific-sidebar-fill`，暗色下形成近黑块，与较亮的轨道反差过大。选择浅而克制的中性底衬，不加品牌色或高对比黑块；图标选中态继续用主文字色，保留键盘焦点轮廓及 reduced-motion。对比过的方向：仅去阴影不能消除黑块；完全去底衬降低三栏辨识；推荐细微浅底衬并去除投影。明暗模式分别验证。

当前图标导航保留24px折叠按钮区，三栏又有上下margin；宿主本身的导航margin/padding可能叠加。只对 Fold 标记且已折叠的导航区域压缩重复留白，保留36px面板按钮与24px折叠按钮命中区域；Tab按钮仍保留现有高度、标签和顺序。不得更改宿主页脚、新会话按钮或整体侧栏宽度。宽侧栏与220px窄侧栏、图标换行、导航展开、原生工作区及活动/收藏均须验证。

## 兼容与机制

DSH 0.2.1-rc.5 和0.2.2-rc.1均保持现有安全回退。仅在已经识别并由Fold标记的节点应用样式，不使用全局button/svg规则，不搬动第三方DOM，不增加ResizeObserver或反复测量。宿主重建、插件卸载和竞争占用时按现有资源生命周期撤回。

## 后续研究结论边界

新会话：uiWorkspace公开startSession，但SidebarRoot内置按钮还涉及会话创建权限、快捷键提示和不同窗口/侧栏状态；操作可调用不等于按钮有可替换插槽，本轮不改。

底部：live `sidebar.footer.action` 已注册 `bot-return`、`agents-anywhere-next` 及 cost-meter 等。该插槽只保证传递 `wide`，未保证每项提供 icon/label/action 的独立数据，因此不能把所有自定义 React 内容无损强制压成一行。已核对 DS Bot 的 `BotReturn` 和 Bridge 的 `ConnectionEntry`：两者实际上都在 `wide=false` 时仅呈现图标；Bridge 的入口还携带弹窗状态/提示，不能仅克隆图标或调用按钮事件代替其行为。推荐先研究自愿接入的图标入口契约、原按钮互斥显示、溢出菜单与未知插件回退，而不是反向嵌套或任意隐藏插件节点；数据摘要、账户菜单不得等同普通入口压缩。

先添加失败回归，再做最小CSS变更。运行完整Node测试、语法和git diff检查；运行设计扫描，检查可自动获取的渲染明暗及窄宽视图。安装成功与live Slot注册不等于真实GUI点击验收，无法认证访问时如实说明。通过独立只读审查后交付原仓库main同名插件的新补丁版本，不覆盖v0.4.10发布物。
