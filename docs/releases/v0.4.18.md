## v0.4.18 · 整理菜单焦点与 Bot 模式快捷键

- 修复通过「活跃整理」快捷键打开菜单后焦点仍停留在侧栏的问题；菜单挂载后会把焦点放入最新菜单的首个可操作项，用户已主动移入色标时不会被延迟逻辑抢回。
- 保留并基于 v0.4.17 的 DSH 0.2.2-rc.2 侧栏兼容修复，不回退导航与滚动网格适配。
- 在 DSH 原生快捷键目录新增「Bot / 经典 Agent 模式切换 / Switch Bot / Classic Agent mode」，无预设键位，用户可自行绑定。
- dsh-nav-fold 通过公开 DOM 事件与 DS Bot 的 surface action 桥接；DS Bot 模式和经典 Agent 模式均可由同一项快捷键切换。
- 新增菜单焦点、快捷键注册／注销和模式切换事件桥接回归用例。

**验收范围：**dsh-nav-fold 全量 Node 回归 179/179 通过；DS Bot 全量测试 2100 通过、3 项跳过、0 项失败，并通过生成客户端一致性检查与 lint。自动化结果不冒称实体遥控器或所有 DSH 版本的现场 GUI 验收。

**安装与回退：**公开附件 `dsh-nav-fold-0.4.18.tgz` 仅通过 GitHub Release 发布，非 npm 发布（`private: true`）。升级后正常重启 DSH；快捷键仍需前往 DSH 设置 → 快捷键自行绑定。上一公开版 [v0.4.17](https://github.com/nico-zhuang/dsh-nav-fold/releases/tag/v0.4.17) 维持不变，作为回退入口。

发行附件 SHA-256：`b6d7bad06259b0709ec2c6c91ef42b5b57b48e374aa7de7735fda03f1652a205`。
