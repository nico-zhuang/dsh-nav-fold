## v0.4.23 · 活跃完成时间排序与市场附件兼容

### 主要变更

- 活跃 Tab 在短时间内连续点击三次时，临时按明确完成时间从新到旧排列。
- 缺少完成时间的会话排在最后，不因缺失字段被丢弃。
- 待处理、运行中和已完成会话均保留在列表中；该隐藏排序不改写 Host 偏好。
- 离开活跃视图后恢复默认排序。
- 排序触发后显示轻量状态提示，并遵循 `prefers-reduced-motion`。
- 活跃行显示相对更新时间；hover/focus 时平滑让位给操作按钮。
- GitHub Release 同时提供带版本号附件 `dsh-nav-fold-0.4.23.tgz` 和市场关联用无版本号附件 `dsh-nav-fold.tgz`。
