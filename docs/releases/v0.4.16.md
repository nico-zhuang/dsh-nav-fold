## v0.4.16 · 活跃行独立柔和行底与状态点前置

- 活跃列表的相邻免打扰（Quiet）行不再连成一块：每行独立 6px 圆角、相邻间隔 2px，保留单行标题和月亮标识。普通活跃行仍是 46px 双行布局，Quiet 为 34px；顶部固定分组、当前选中、悬停、键盘焦点及 3px 手动冷色色条保持各自语义，保留整理菜单 v0.4.15 的 C「紧凑色条」布局。
- 活跃列表普通行的 Host 状态点紧靠第二行工作区名称前方，完成未读为绿、待处理为黄、运行中为蓝；空闲不增加点。运行中的呼吸与减少动态效果适配不变。免打扰月亮不混作状态点；收藏列表仍保持原来的「工作区名称 → 状态点」顺序。
- 行内操作按钮占据独立预留区域，活跃普通行剩余空白仍可点开会话；宿主菜单、快捷键、Host 偏好字段和状态来源均未变。
