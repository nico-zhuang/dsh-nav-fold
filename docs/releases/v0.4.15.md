## v0.4.15 · 活跃会话整理菜单紧凑排布

- 「色标」下无色与五个原有冷色色标改为**六个横排**；每个色标仍有 30×30 CSS px 独立触点、当前值边框和中英文可读名称。左右键逐个移动（首尾环绕），上键回到免打扰，下键进入自定义色，Home／End 和 Tab 的原有边界仍保留。
- 已保存自定义颜色时，底行的「使用自定义颜色」与右侧 **独立铅笔编辑按钮**分别可点击、可聚焦；铅笔打开原 HEX 取色器，不会因使用颜色而误进入编辑。未保存时显示「自定义颜色…」。Host v1 配置序列化、失败重试、取消与焦点恢复保持不变。
- 活跃列表的 Quiet 会话标题收为一行并保留小月亮；相邻 Quiet 行的背景相连，顶部固定组与普通行截断连接。非 Quiet 行与其他 Tab 的原有两行布局不变。v0.4.14 的会话导航和整理快捷键照常使用。

**验证范围：**177 项串行自动化测试通过（原插件回归 174 项＋新版合成菜单预览 3 项），包括 DSH 0.2.1-rc.5 和 0.2.2-rc.1 两套菜单夹具；旧 v0.4.14 的十二张历史素材仍有单独的字节级重现测试。另将未发布候选测试包安装到独立 QA profile，在真实 DSH 菜单深色和浅色主题下测得 Host 浮层宽 214 CSS px、六色网格宽 206 CSS px，不裁剪色标或独立铅笔；实际键盘 Tab 到达铅笔，点击铅笔打开 HEX 窗口、取消后焦点返回菜单锚点。README 新菜单图仍为**匿名离线合成示意**，不是已登录 DSH 截图；未以此宣称实体遥控器、所有视口或所有插件路径已经现场验收。

**配置边界：**在已核对的默认 DSH 桌面 Web 连接模式下，每个 profile 有独立页面地址与 Host 上下文；客户端排队中的表单写入仍发往其页面相对 HTTP 地址，Host 再使用该 profile 固定的配置路径与锁。因此同 raw 的 A/B 在途写入不会因默认连接重连而混写。此结论有打包版 Host 源码调用链与本机两独立 profile 服务作为依据，**不外推到自定义传输覆盖、反向代理转发同一地址给不同 profile 或复用端口的部署**；这类环境应单独验证后再启用。
