## v0.4.19 · 活跃会话拖动排序

- 活跃视图的会话行现在支持桌面拖动排序。
- 拖到「顶部固定」区域会设置为顶部会话；顶部区域为空时也有可放置区域。
- 在同一系统状态组内拖动可调整顺序，支持拖到目标行前后以及列表底部。
- 系统状态优先级仍然高于人工顺序：待处理、运行中、完成未读不会因为拖动被压到普通最近会话之后。
- 拖动顺序保存到当前 profile 的 Activity 偏好中，重载和重启后保留；Quiet 仍是独立语义，不会因为普通拖动被隐式设置。
- Favorites 和 Workspaces 不参与这套 Activity 人工排序。
- 新增拖动事件、顶部空 drop zone、同状态组排序、持久化和状态优先级回归测试。

**验收范围：**dsh-nav-fold 全量 Node 回归 181/181 通过；DS Bot 配套桥接不变。自动化结果不冒称实体遥控器或所有 DSH 版本的现场 GUI 验收。
