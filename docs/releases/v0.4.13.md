## v0.4.13 · 活跃列表分组、冷色色标与浏览期保序

- 活跃列表把手动「固定在顶部」的会话置于独立的「顶部固定」标题与分隔线之前；没有固定行就不显示空分组。「固定在顶部／取消顶部固定」只影响活跃列表，不等于 DSH 原生 Pin，也不会改变收藏。
- 五种人工色标改为青蓝、钴蓝、靛蓝、雾紫、银灰，浅色主题采用更明晰的高饱和冷色；左侧 3px 色条上下各留 4px。旧 Host v1 颜色槽位保持兼容，不会重写已有偏好。点选已选色可清除。
- 点开完成未读（绿点）会话时，真实已读状态和圆点立即更新；只在本轮浏览活跃列表期间保留行在原绿灯队列中的位置，避免跌出近期 20 条而消失。新审批、重新运行与手动固定仍优先；离开活跃列表再回来，按真实状态重新排序。
- 「免打扰」仅让活跃行视觉变淡并显示月亮，不停任务、不静音通知或审批提醒；收藏与原生会话菜单维持原有行为。活跃偏好存于当前 DSH profile 的 Host 配置，重启及 localhost 端口变化后仍可读取。
- 修复 Quiet 与浅色选中行的 11px 次要文字对比不足，并扩展 Host 主题检测对短 HEX、sRGB、OKLCH 及中间主题容器切换的兼容。

**验证范围：**141 项自动化测试通过；正式 `.tgz` 的 6 个文件与源码逐字节一致。Chrome 中用模拟会话检查过深浅主题、220/320px 宽度及键盘焦点，合成页面 axe WCAG A/AA 为 0 项违规、1 项无法自动判定。**尚未完成已登录真实 DSH GUI 的本版视觉与点击现场验收；合成样张不等于已认证截图。**
