## v0.4.14 · 活跃会话整理快捷键与实时绑定状态

- 新增不预设键位的「活跃整理 / Organize focused Activity session」原生快捷键：只在「活动」栏某个会话行**明确获得键盘焦点**时打开该行自己的整理菜单；选中会话、其他栏目、弹窗、终端或没有可用菜单时不猜测、不执行。DSH 0.2.2-rc.1 打开 Fold 独立整理菜单，不会触发宿主原生三点菜单；DSH 0.2.1-rc.5 使用该行由 Fold 绘制、包含整理项的兼容操作菜单，不触发宿主原生菜单。
- 原有「会话导航 / Navigate sessions」的 ↑↓ 焦点移动、←→ 切栏、Enter 确认与 Esc 退出不变。关闭导航开关时释放焦点模式，但两项原生快捷键命令仍在 DSH 快捷键目录中可见，已设的绑定不会因开关切换被覆盖。
- 插件配置页从 DSH 原生快捷键目录实时显示这两项命令的已绑定／未绑定状态和键位；绑定、修改和冲突处理仍前往 **DSH 设置 → 快捷键**。未自建录制器、未另存按键，自动更新限同一 DSH 窗口。

**验证范围：**144 项自动化测试通过，包括 rc.5 实际渲染的活动会话行菜单、焦点与无匹配行回退；`lib/client.js` 语法检查与 `git diff --check` 通过；发布 `.tgz` 的 6 个文件与源码逐字节一致。**尚未在已登录真实 DSH GUI 验证新快捷键的按键派发或用实体小米遥控器和「无线麦」现场验收；自动化测试不等于现场验证。**
