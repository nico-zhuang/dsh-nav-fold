## v0.4.22 · Web 侧栏 DOM 兼容

本版将 PR #4（`fix: support current Web sidebar DOM`）的兼容改动与 v0.4.21 的稳定功能合并发布。PR 代码已在本地提交 `471324f`，没有直接改写或另行合并 GitHub PR；发布基于当前工作树中的合并结果。

### 主要变更

- 兼容当前 Web 版侧栏 root class，并保留旧 Desktop DOM selector。
- 兼容新的 region / footer class，以及新的 collapsed class。
- 使用通用 `logoRow` selector 隐藏品牌行。
- Web 版隐藏品牌时保留侧栏切换按钮，避免品牌行隐藏导致导航入口丢失。
- 保留 v0.4.21 的活跃视图运行中／完成未读／常规会话跨类型手动排序、Command / Ctrl / Shift 非连续多选整体拖动、拖动占位与目标让位、FLIP 放置动画、活跃行底色淡入淡出、Quiet 圆润闭合弯月图标，以及无历史 order 的新会话回到默认状态排序并在同状态内按更新时间靠前。
